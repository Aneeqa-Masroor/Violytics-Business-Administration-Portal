📊 Analytical Business Administration Portal

A modern, feature-rich, and interactive Business Administration Dashboard built with React, Tailwind CSS, and JavaScript. Designed to provide a centralized view of business operations, the portal combines data visualization, interactive analytics, product management, order tracking, and customer insights in a clean, professional interface.

Powered by structured JSON mock data, the application delivers a dynamic dashboard experience with comprehensive search capabilities, advanced filtering, interactive charts, and a customizable dark and light theme.

✨ Key Features

📈 Interactive Overview Dashboard – Get a comprehensive overview of business performance and key metrics.

📦 Order Management – Explore and review order-related information through a dedicated orders page.

🛍️ Product Management – Browse product data with convenient search and filtering functionality.

📊 Analytics Dashboard – Explore business insights through interactive charts and visual data representations.

👥 Customer Management – Access customer information through a dedicated customer section.

🔎 Global Search Functionality – Search across available products and other supported dashboard data.

🧩 Advanced Filtering – Filter data using available search filters, categories, and date options.

📅 Date-Based Filtering – Refine displayed information using date-related filter controls.

🖱️ Clickable Interactive Charts – Interact with chart elements to explore relevant data and insights.

🌙 Dark & Light Mode – Switch between dark and light themes for a personalized viewing experience.

🗂️ JSON Mock Data Integration – Display structured business data using local JSON files.

🎨 Modern UI/UX Design – Enjoy a polished dashboard interface with organized layouts and intuitive navigation.

⚡ Dynamic User Interactions – Experience responsive interface updates through React and JavaScript.

⚙️ Installation & Setup

Follow these steps to run the project locally.

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory

cd Analytical-Business-Administration-Portal

3. Install dependencies

npm install

4. Start the development server

For a Vite-based React project:

npm run dev

Open the local URL displayed in your terminal to view the application.
